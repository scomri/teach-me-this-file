# Glossary

- **Step:** One planned teaching unit with an objective, check question, key points and source chunks.
- **Key point:** A fact or idea in the plan that a good answer to a step's check question should cover.
- **Check question:** The question used to assess the student's understanding of a step. It asks the student to apply the step's idea to a case, not to repeat the passage.
- **Evaluation:** The model's structured classification of a student message, including key points met and relevant source chunk ids; code validates it and decides what follows.
- **Transition:** The move selected by code for the next tutor reply, such as nudge, reveal, advance or recap.
- **Mastered:** A step whose key points the student covered before its answer was revealed.
- **Revealed:** A step marked for an answer reveal after repeated unsuccessful attempts or requests for the answer; the reply can still be stopped or fail.
